# GDG Git Workshop — Demo Project

A simple Python calculator built step-by-step to learn Git.

## Setup

```bash
git clone https://github.com/YOUR_USERNAME/demo-project.git
cd demo-project
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Run Tests

```bash
pytest tests/
```
